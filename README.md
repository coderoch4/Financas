# Minhas finanças

1. Supabase: SQL Editor > cole `supabase/schema.sql` > Run.
2. Copie `.env.local.example` para `.env.local` e preencha com URL e anon key (Project Settings > API).
3. `npm install` e depois `npm run dev` > http://localhost:3000
4. Vercel: importe o repositório e cadastre as 2 variáveis em Environment Variables.
